onyxchat/ — estrutura do projecto
=====================================================================
Reconciliado com o código em 2026-10-07 (B5).

Este ficheiro é um **mapa, não uma fonte de verdade**. A fonte de
verdade é a árvore de ficheiros, e `scripts/verificar_estrutura.py`
confere que os dois concordam — porque um mapa desatualizado é pior do
que não ter mapa: dá para responder com confiança a uma pergunta cuja
resposta já não é verdade.

O que mudou face à versão anterior está em §O que a versão anterior
inventava, e são sete ficheiros.

**Onde vive este ficheiro mudou em 2026-10-07.** Estava um nível acima,
fora do repositório. Foi por isso que apodreceu em silêncio: um ficheiro
que não está no repositório não é versionado, não é clonado, e não pode
ser conferido por um workflow — as três coisas que mantêm um mapa
honesto. Passou a estar na raiz, e `scripts/verificar_estrutura.py`
confere-o em cada push.

# Mapa das nove camadas
---------------------------------------------------------------------
| Camada | Onde está              | Nota                                   |
| ------ | ---------------------- | -------------------------------------- |
| K1     | crypto/rust/src/aead_chacha.rs | AEAD do canal de sessão           |
| K2     | crypto/python_lua/lua/deslocamento.lua | deslocamento +3         |
| K3     | crypto/python_lua/lua/vigenere.lua     | Vigenère                |
| K4     | crypto/c_cpp/transposition.cpp         | 5 colunas + PKCS#7        |
| K5     | crypto/rust/src/aead_aes.rs | AES-256-GCM                       |
| K6     | crypto/python_lua/lua/playfair.lua     | Playfair               |
| K7     | crypto/rust/src/hill.rs      | Hill 2×2 mod 256                    |
| K8     | crypto/python_lua/lua/deslocamento.lua | deslocamento +7         |
| K9     | crypto/c_cpp/k9_chacha.c | libsodium, com espelho em Rust     |

**K2 e K8 são o mesmo módulo**, com deslocamentos diferentes. São a
única camada implementada duas vezes, e é de propósito: um único módulo
elimina a classe de bug em que as duas divergem sem nenhum teste as
distinguir. `network/daemon_rust/src/lua_camadas.rs` documenta o porquê.

# O que a versão anterior inventava
---------------------------------------------------------------------
A versão anterior listava sete ficheiros que **não existem**. Estavam lá
desde antes de o código os substituir, e ninguém notou porque um mapa
não se executa:

| Ficheiro listado                    | Realidade                              |
| ----------------------------------- | -------------------------------------- |
| `crypto/python_lua/python/*.py` (4) | A referência em Python **não existe**  |
| `~crypto/python_lua/lua/cesar.lua` | K2 passou a `deslocamento.lua`         |
| `~crypto/python_lua/lua/substituicao.lua` | K8 passou a `deslocamento.lua`     |
| `~messenger/plugins_loader.py`       | Não existe plugin loader              |

Faltavam inteiros: `scripts/`, `fuzz/`, `tests/` quase todo, a
`UI/` inteira, `messenger/conta.py`, `server/loja.py` e os quatro
ficheiros Rust que não constam de lado nenhum.

Cada uma destas linhas é agora conferida por
`scripts/verificar_estrutura.py`, que falha se um ficheiro aqui deixar
de existir — que é o que teria apanhado a versão anterior.
