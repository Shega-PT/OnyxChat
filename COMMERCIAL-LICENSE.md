# Template de Licença Comercial — OnyxChat

> **Isto é um andaime de redacção, não um documento juridicamente
> revisado.** Cada cláusula está aqui com o efeito explicado para que
> adapts caso a caso apagando linhas, e não para substituir a revisão de
> um advogado. Mostra-o a um advogado em Portugal **antes** de emitires a
> primeira licença a um terceiro — sobretudo se o licensee for consumidor
> final em vez de empresa, porque os tectos de responsabilidade e as
> indemnizações têm limites legais diferentes.

Este template existe porque a licença base (`LICENSE`) é a **PolyForm
Noncommercial 1.0.0**, que proíbe o uso comercial. A autorização para
comercializar é um documento separado — este — emitido por quem tem
autorização para o fazer. Ver `AUTHORIZED.md`.

---

## Como usar este template

1. Copia o ficheiro para `COMMERCIAL-LICENSE-<licenciado>-<data>.md`
   (ou para o formato que preferires).
2. Preenche os campos `«...»`.
3. **Apaga** as cláusulas que não aplicarem, e as linhas inteiras de
   instrução (começadas por `APAGAR`).
4. **Decide conscientemente** cada `PREENCHER`: a escolha que fica por
   omissão é a mais permissiva, e quase nunca é a que queres.
5. Remove esta secção de instruções do documento final.
